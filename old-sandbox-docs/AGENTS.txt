Security issue documentation
----------------------------

When a review finds a security boundary issue, document the authority involved,
the untrusted action it permits, the affected trusted asset or policy, the
mitigation, and the residual limitation. Add stable glossary definitions for
new security terms and link review-ledger findings to those definitions.
